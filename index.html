AI 챗봇 연결 (Anthropic API)

API 키를 넣으면 챗봇이 자연어를 이해해서 업무를 정리·등록하고, 부족한 정보를 되묻습니다. 키가 없거나 연결이 안 되면 기본(규칙) 모드로 동작합니다. 키는 이 PC 브라우저에만 저장됩니다.

기본값

공지 사전 표시일(시작일 x일 전부터 표시) 기본값 일

데이터 백업 / 복원

로그인하면 업무·휴일·기본값이 클라우드(Firebase)에 저장되어 모든 기기에서 같이 보입니다. 로그인하지 않으면 이 PC 브라우저에만 저장됩니다. API 키는 클라우드에 올리지 않고 PC마다 따로 저장합니다.
